Privacy Policy

Last Updated: May 22, 2026

This Privacy Policy applies to the virtual reality application “Running Studies In The Wild v1”.

The Application was developed as part of an academic seminar project focused on evaluating and documenting deployment and distribution workflows for virtual reality applications.

Purpose of the Application

The Application is a technical prototype used for research and educational purposes. It allows users to move within a simple virtual environment in order to evaluate VR deployment and distribution methods.

Data Collection

The Application does not intentionally collect, store, process, transmit, or share personally identifiable user data.

The developer does not collect:

  • User accounts
  • Email addresses
  • Names or profile information
  • Gameplay statistics
  • Analytics data
  • Cloud saves
  • Uploaded files
  • Study responses
  • Eye tracking data
  • Body tracking data
  • Microphone recordings

No user data is stored locally by the Application or uploaded to external servers.

Technical Processing

The Application uses components of the Meta All-In-One SDK and related VR framework dependencies required for basic VR functionality, including controller tracking, hand visualization, locomotion systems, and VR camera rig functionality.

Certain technical information may therefore be temporarily processed by the Meta Quest platform or operating system during runtime, such as:

  • Device and hardware information
  • Tracking data required for VR rendering
  • Controller position and movement data
  • Hand tracking visualization data
  • Performance diagnostics or crash information handled by the platform

This technical processing is required for the Application to function correctly in virtual reality environments.

The developer of the Application does not access, store, analyze, or distribute this technical information.

Third-Party Services

The Application relies on services and runtime components provided by Meta Platforms Technologies, LLC and the Meta Quest platform.

These services may process technical information according to Meta’s own privacy policies and platform terms.

Meta Privacy Policy: https://www.meta.com/legal/privacy-policy/

Data Deletion Requests

Since the Application does not collect or store personal user data, there is generally no stored user information that requires deletion.

However, if you have privacy concerns or would like to request confirmation regarding data handling, you may contact the developer at the email address below.

Children’s Privacy

The Application is not specifically directed toward children under the age of 13.

Security

No databases, cloud infrastructure, user accounts, or backend services are operated by the developer for this Application.

This Privacy Policy may be updated in the future to reflect changes to the Application or project requirements. Updated versions will be published on this page.
